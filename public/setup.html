CMULTIMEDIA Deck — installation sur l'iPad

Tout reste sur ton réseau local. Aucun port n'est ouvert sur la box.

Le plus simple : tout installer d'un coup

Installer le profil Deck (certificat + icône)

Touche Installer (code de l'iPad), Installer, OK. L'icône « Deck » apparaît sur l'écran d'accueil : ouvre-la et saisis le code d'association. Les étapes 1 à 3 ci-dessous ne servent alors plus.

1. Installer le certificat du deck (une seule fois)

Le Mac chiffre les échanges (micro, photos, clavier, souris) avec son propre certificat. Pour que l'iPad lui fasse confiance :

Télécharger le certificat du deck

Safari propose « Installer le profil » : touche Installer (code de l'iPad), puis Installer encore et OK. Sur iOS 9, aucune autre activation n'est nécessaire.

Empreinte SHA-256 à comparer avec celle affichée par ./deck doctor sur le Mac : voir ./deck doctor

2. Ouvrir le deck en https

Ouvrir le deck chiffré

3. Ajouter l'icône à l'écran d'accueil

Dans Safari, sur la page https du deck : bouton Partager (carré avec flèche) puis Sur l'écran d'accueil, nom « Deck ». Ouvre ensuite le deck depuis l'icône et saisis le code d'association affiché sur le Mac. L'icône s'affiche en plein écran, sans barre Safari.

Si la connexion chiffrée échoue

Le deck ne fonctionne qu'en https : l'association et les commandes ne circulent jamais en clair sur le Wi-Fi. Vérifie que le certificat est installé (et, sur iOS 10.3 ou plus récent, activé dans Réglages › Général › Informations › Réglages des certificats), puis rouvre l'adresse https. Ne saisis le code d'association que sur une page avec le cadenas.
